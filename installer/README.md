# Windows release packaging

Run `powershell -ExecutionPolicy Bypass -File build-installer.ps1` from the project root. This publishes a fresh, self-contained .NET 10 x64 application, generates the portable ZIP, and compiles `DiskSpaceAnalyzer-Setup.exe`. `-SkipPublish` reuses the clean staging directory recorded by the last successful `build.ps1`; it requires a self-contained publish.

Build tools: .NET 10 SDK (`tools/dotnet/dotnet.exe`, or `dotnet` on PATH), Inno Setup 6.7.4+ (`tools/InnoSetup/ISCC.exe`). End users need neither tool nor a separately installed .NET runtime. Build tools and source backups are excluded from release packages.

The installer supports English and Korean. It installs per user in `%LOCALAPPDATA%\Programs\DiskSpaceAnalyzer`. Everything is detected from its running default instance, the saved path, HKCU/HKLM App Paths (both registry views), and Program Files. Missing Everything is installed using `winget install --id voidtools.Everything --exact --source winget --architecture x64 --scope machine --installer-type nullsoft --silent --accept-package-agreements --accept-source-agreements --disable-interactivity`. If unavailable or unsuccessful, Setup uses the bundled official installer below. The Everything service installation can require UAC approval. Setup and normal application startup share service provisioning: check the Service Control Manager for a running, automatic Everything service before accepting any database response. Missing, stopped, manual/disabled services and leftover run-as-administrator configuration are repaired by one elevated application helper. The helper gracefully restarts Everything, installs/starts the service and disables administrator GUI startup (backing up Everything.ini before changing that flag). Then the normal-user process starts the GUI in the background and waits up to three minutes for a nonempty file index. A successful query returning zero files is not considered ready. Service repair errors are saved in %LOCALAPPDATA%\DiskSpaceAnalyzer\EverythingServiceRepair.log.

Bundled fallback: [Everything 1.4.1.1032 x64](https://www.voidtools.com/Everything-1.4.1.1032.x64-Setup.exe). Place the unchanged installer in `installer/vendor/`. SHA-256 is checked both by the build script and immediately before execution:

`C42EFAD041D4C0BB4D4AC97AE7CBE89F153EC1FE078772392E749C7F5D5282D3`

The installer excludes the portable Everything engine executable. The ZIP includes it for portable use. Both include the Everything SDK DLL and licenses. App uninstall preserves Everything, `%LOCALAPPDATA%\DiskSpaceAnalyzer` user data, and HKCU language/dependency preferences. Only Explorer context menus owned by the installed executable are removed. The setup is currently unsigned; production code signing requires the distributor's certificate.

Localization: `src/Core/Localization.cs`, `src/Controls/TrExtension.cs`, and `src/Resources/Strings[.ko].resx`. English is the fallback language; Korean Windows defaults to Korean. Installer selection initializes the preference, and the compact KO/EN menu changes it immediately. Preference: `HKCU\Software\DiskSpaceAnalyzer\Language`. Translations are keyed by resource name in `tools/localization/translations.json`; run `tools/localization/build-resources.ps1` after updating translations. Preserve resource backups before regeneration. The one-time Roslyn migration tool is historical tooling and must not be rerun against already localized sources.

Offline: the official dependency installer and .NET runtime are embedded, so WinGet/network failure can use the bundled fallback. The first index still needs access to the target drives. Windows 10 version 1809+ x64 or Windows 11 x64 is required; Windows ARM is not a tested target.
